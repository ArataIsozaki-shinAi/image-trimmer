Google Cloud で作成した「ウェブ アプリケーション」用のクライアントID（公開情報・シークレットではありません）を貼り付けてください。作成手順を表示
OAuth クライアントID の作成手順
  1. Google Cloud Console でプロジェクトを作成（無料）
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を有効化
  3. 「OAuth同意画面」を構成: User Type =「外部」、アプリ名等を入力。スコープに .../auth/drive.file を追加し、テストユーザーに自分のGoogleアカウントを追加（公開は不要・「テスト」のままでOK）
  4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類「ウェブ アプリケーション」
  5. 「承認済みの JavaScript 生成元」に https://arataisozaki-shinai.github.io を追加（保存）
  6. 表示された クライアントID をコピーし、上の欄に貼り付けて「接続」
※ アクセス範囲は drive.file（このアプリが作成したファイルのみ）に限定。画像はブラウザから直接 Google にアップロードされ、当サイトのサーバーには送信されません。
※ OAuthはHTTPSが必須のため、ローカルの file:// では動作しません（本番URLでご利用ください）。
